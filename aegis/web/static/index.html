What this shows

An AI agent reads untrusted emails and files and may draft or send mail. Every tool call passes a deterministic policy gateway before it runs. The gateway, not the language model, has the final say. A threat detector can only make a decision stricter, never looser.

Configurations

  • A - unprotected: the agent runs with the user's full permissions.
  • B - detector only: sends are blocked when the detector flags the input (or fails).
  • C - gateway only: policy gateway and approvals, no detector.
  • D - Aegis: gateway plus detector.

Approvers

  • manual: you approve or reject each sensitive action in the UI.
  • intent: a careful human who checks recipients and attachments against the task.
  • rubber_stamp: approves everything (worst case for the human).
  • reject_all: approves nothing.

All data is synthetic and all tools are simulated. Nothing leaves this process. Email and file bodies are shown on purpose so you can see the hidden instructions.
